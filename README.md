# autoClicker  

A small Python script that automates mouse clicks at predefined screen positions. Useful for repetitive GUI tasks, testing, or any application requiring automated clicking.  

## Key Features  
- Clicks on multiple predefined screen positions in sequence  
- Configurable delays between actions  
- Repeats the click sequence a specified number of times  
- Simple to modify for different coordinate sets  

## Requirements  
- Python 3.x  
- PyAutoGUI
